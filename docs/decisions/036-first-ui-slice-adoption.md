# 036 — Adoption bornée de Tailwind et React Aria pour UI-ARCH-03

**14 novembre 2026 — Adoption autorisée par le mandat explicite d’exécution UI-ARCH-03 avec alignement des autorités avant code.** La qualification et l’acceptation visuelle restent à établir.

La prescription CSS du cahier des charges est alignée : Tailwind v4 et React Aria Components sont adoptés pour navigation des scènes, saisie de valeur précise et dialogue d’abandon du brouillon, avec HTML sémantique et CSS spécialisé. Les autres surfaces conservent leurs styles et comportements. DTCG reste l’autorité, thème outil dérivé ; le writer projet ne peut modifier les valeurs outil. Pas de Preflight global, pas de nouvelle propriété éditable ni de migration de données.

Cette décision applique le [cadrage 035](035-ui-architecture-boundaries.md) et son [contrat](../architecture/ui-architecture-boundaries.md). Le mandat autorise l’alignement du cahier des charges, propriétaire lab, sans modification des instructions d’agents. Les projets déjà créés, profils de création/export, socle des nouveaux projets et Electron ne sont pas réalisés dans cette tranche. Swift/WKWebView reste le contenant. Versions, contrôles et limites seront consignés dans [UI-ARCH-03](../work-items/ui-arch-03-first-ui-slice.md).
