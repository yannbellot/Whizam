# Organisation des tokens

La [politique du design system](policy.md) est l’autorité courante : primitives, tokens de composant et tokens locaux de page. Le JSON DTCG porte les valeurs/références, le registre YAML les composants et exemples, et les recettes YAML les expressions CSS contextuelles.

Le partage d’une valeur ne crée pas une intention commune. Réaffecter explicitement les usages pour une modification globale. Documenter les tokens locaux par page sans les exposer comme API du design system ; une apparence de composant différente exige une variante.
