# Travailler avec l’assistant

Exprimez ce que la personne qui utilisera votre application doit pouvoir comprendre ou faire. Situez votre demande dans une page ou un parcours et indiquez les contraintes à préserver. Fournissez seulement les références et contenus que vous êtes autorisé à partager.

## Formuler une demande exploitable

> « Sur la page Contact, le visiteur doit comprendre les champs obligatoires avant l’envoi. Prépare une proposition en conservant les autres pages. Voici les textes et la référence visuelle. »

Précisez si vous attendez une explication, une préparation ou une réalisation. Une demande de préparation produit un périmètre et des critères à examiner ; elle ne lance pas le développement. Pour une réalisation, l’assistant analyse la demande et applique les règles de validation du kit. Une autorisation déjà reçue pour le même périmètre n’est pas à redonner à chaque opération.

Vous devez pouvoir identifier le résultat prévu, les éléments provisoires, les vérifications et les décisions qui vous reviennent. Si une proposition est trop vague, demandez une formulation observable avant de décider.

## Comprendre les échanges

Les questions utilisent les contrôles natifs du client lorsqu’ils sont disponibles et autorisés. Si une question n’est pas cliquable, répondez par son libellé en texte ou demandez une liste numérotée. Le kit ne garantit pas un rendu identique dans tous les assistants.

Une recommandation de modèle ou de niveau vous aide à choisir une configuration ; elle ne change pas automatiquement votre outil. Les [adaptations et leurs limites](../compatibility.md) distinguent ressources présentes et essais réalisés.

Ne transmettez pas de mot de passe ou de clé dans la conversation. L’assistant doit expliquer les champs nécessaires et proposer la [saisie privée locale](../agents/private-configuration.md), avec un repli fichier si nécessaire.

Pour préciser un besoin : [Cadrer une première version](cadrer-version.md). Les [instructions du kit](../../AGENTS.md) et le [protocole de décisions](../agents/user-decisions.md) restent les règles de référence.
