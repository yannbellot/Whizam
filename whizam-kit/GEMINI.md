# Instructions du kit — Gemini CLI

Lire `AGENTS.md`, autorité de collaboration active, puis `docs/agents/skill-contract.md` et `agents/builder.md`. Les rôles dans `agents/` s’exercent séquentiellement par défaut ; aucune délégation ni autorisation fournisseur n’est ajoutée par ce fichier.

Appliquer le [cadrage initial](docs/agents/project-intake.md) : questions conditionnelles, second niveau en conversation et reprise depuis le brief/suivi. Ne pas demander quel assistant est utilisé ; suivre sa politique par point d’entrée. Recueillir les langues documentaires en Q10 seulement si elles manquent, selon [Langues du projet](docs/agents/languages.md).

Pour les décisions utiles, appliquer `docs/agents/user-decisions.md`. Utiliser les choix natifs si disponibles et autorisés, avec instruction complémentaire facultative. Sinon, repli texte ; aucune interface ni sélection effective de modèle n’est présumée.

Les sources uniques des skills sont dans `skills/`. Lire `docs/agents/adapters.md` pour découverte, activation et limites. Les chemins du contenu des skills partent de la racine du dépôt. Préserver les approbations natives de l’outil ; aucune instruction Markdown ne les remplace.
