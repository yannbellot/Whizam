# Project roadmap

**Status: initialize when starting a project.** No derived project is defined here. The starter and its example are not business objectives for the future project.

## Initialization

From the brief and user mandate, record project name, objective, selected scope, exclusions and success criteria. Then define initial milestones and dependencies. The presence of this template opens no work item.

## Milestones and work items

Complete after scoping. For each work item: identifier, objective, dependencies, criteria, status and link to its useful file. Distinguish To do, In progress, In review, Accepted and Blocked; technical qualification does not replace required human acceptance.

## Tracking

Keep consolidated project statuses here. The [resumption note](docs/project-state.md) stays short; [conventions](docs/conventions.md) define specification, work item, decision and evidence locations. [Instructions](AGENTS.md) govern mandate/permissions. A roadmap authorizes neither publication nor data operations.
