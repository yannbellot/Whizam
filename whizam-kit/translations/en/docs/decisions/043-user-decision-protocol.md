# 043 — Common question and verification protocol

> Revision, 20 November 2026: [decision 044](044-project-intake-and-entry-policies.md) supersedes assistant selection and initial language ordering. The text below remains historical.


**Date:** 19 November 2026.  
**Status:** implementation requested by the kit owner after preparation/adjustments; delivery subject to review.

## Decision

Adopt the [common protocol](../agents/user-decisions.md) under AGENTS: context/scope, explicit question, available native options and optional supplementary instruction. Initial choice is an exception: “To begin, which assistant are you using?” with Codex (OpenAI) / Claude Code (Anthropic), no requested supplementary comment. Explicit declarations/other tool adapters remain supported.

For relevant reviews, choose Manual / Automated — E2E / Combined with coverage/recommendation. Reuse for same-scope retests. Distinguish choice, execution approval, manual observation, E2E evidence and result acceptance. Contradictory answers/material conditions must be resolved before dependent action. Silence/automatic returns never imply agreement.

## Scope

Complements 041/042 without changing models/effort thresholds, priority client permissions, mandatory checks or existing bounded diagnosis. No attempt threshold added. No custom interface, provider installation or automatic personal setting. E2E does not replace design/technical/security reviews.

Native selector/field availability depends on the client; text fallback preserves explicit decisions. Structural/documentary checks prove neither interactive rendering nor native assistant behavior. Maintenance tracking stays outside distribution and project templates stay unchanged.
