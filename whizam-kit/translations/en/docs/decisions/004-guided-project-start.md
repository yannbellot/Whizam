# 004 — Guided startup and first-version review

**25 October 2026 — direction approved by the owner.** Implementation qualification and human acceptance remain separate.

> Revision of 19 November 2026: [decision 041](041-request-validation.md) requires an approved proposal before initial execution. The [current workflow](../product/project-start.md) applies this rule; initial provisions below remain historical.

## Context

Initialization collected application type but delivered only environment/demonstration. Its response suggested a delivered application with technical information imposed by multiple sources. Prior communication clarification did not resolve the workflow contract.

## Decision

The [startup workflow](../product/project-start.md) separates initialization, first-version scoping, design/development and first-version review. initialize-project retains technical responsibility under decision 002; the Builder hands subsequent work to existing procedures within sufficiently defined authorized scope. Preparation-only or technical-initialization-only requests never become implementation authorization.

Present Application and Storybook — project component links together at first review after checking the agreed result. Servers can be used earlier for internal checks. Retain technical evidence/statuses in tracking; designer messages explain result, limits and next steps without imposed technical lists.

Keep `/projects` as a starter manufacturing reference. In derived projects remove demonstrations from navigation/delivered access points or replace under project specifications, updating tests/stories/documents. No implicit data deletion. Kit examples/generic components remain available for building/testing.

## Consequences

No new skill, orchestrator, access mechanism, stack, external service or permission. Common instructions/procedures link canonical workflow/communication sources. Existing projects resume missing sequences without reinitialization. Historical evidence remains version-bound. Written instructions prove neither native behavior nor human understanding.
