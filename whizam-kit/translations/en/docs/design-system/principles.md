# Design system principles and usage

Reuse existing components; create only tokens and variants needed by the requirement. The [current policy](policy.md) distinguishes primitives, component tokens and local tokens. Every change preserves states, behavior and keyboard/focus checks and makes changed usage explicit.

The assistant maintains sources/examples; scripts validate/generate; the designer reviews the result in the application and Storybook. Examples are fictional and do not prove business persistence. Storybook saves no visual settings.
