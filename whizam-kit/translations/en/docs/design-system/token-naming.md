# Token naming

Under the [current policy](policy.md), use `primitive.*`, `component.*` or `local.*`; technical identifiers are English, stable and explicit. An identity includes an owner and usage; components distinguish variant, part and state. Metadata carries category/owner and component context where needed.

Do not introduce semantic/decision prefixes, instance exceptions or component-token references to other components. Retained historical identifiers and mappings are in the [migration table](simple-token-migration.json). CSS variables are derived outputs, not the naming source.
