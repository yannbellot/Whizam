# Standalone kit distribution

The Whizam Kit, formerly Loomata, ships in this folder. Its visible name changes; existing paths, commands, project formats and technical identifiers are retained. Historical references below keep their dated scope.

The Zensical documentation portal ships here with scripts and Docker configuration. See the [usage guide](../documentation.md). Neither parent files nor host Python are required.

DS-AUTO-01 edition of 18 November 2026: automated design system with three token categories, read-only Storybook and UI Lab removal. Historical provenance remains `e81cabc78cd6c9d4263961dc03511dbec0e14ac1`; this reference does not represent changes in this local edition without Git.

The folder containing this notice is the complete distribution unit. All README commands run from its root; no external maintenance folder is needed. Preserve hidden files and relative skill links.

## Content and checks

`sources.json` inventories shipped sources with hashes or link targets. Installations, caches, private configuration, journals, data and builds are excluded. Dependencies install from the npm lockfile; no account, Docker volume or system setting is transferred.

The [DS-AUTO-01 report](ds-auto-01.md) describes this evolution’s checks/limits. [Initial DIST-01 qualification](qualification.md) remains historical evidence of its former scope. Dated reports do not automatically qualify a new edition.

Recipients follow the README and use their own assistant. Local instructions do not guarantee native discovery by every tool; see [compatibility](../compatibility.md). Distributed projects are not migrated implicitly.

## Limits

Retained historical utilities/sources from other workflows are not required installation steps. The old editor is no longer active; its journals/receipts are not converted by source migration.

Kit presence is neither human acceptance, an additional license, publication nor production readiness. This evolution transfers no user data and changes no PostgreSQL/Docker prerequisites.
