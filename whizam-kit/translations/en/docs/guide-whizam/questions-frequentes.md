# Frequently asked questions

## Is an empty application normal?

Yes, in a new kit. The application awaits your content. Storybook already displays Foundations, Components and Patterns, even when empty, without default examples. Only elements created or adopted for your project appear. Initialization prepares work; a first version follows scoping and implementation. See [Creating your first project](premier-projet.md).

## Where is my project?

In the kit copy you are using. Its business name can differ from the folder name. Ask the assistant to confirm the target root before an operation. See [Preparing your kit](preparer-kit.md).

## How do I open Application, Storybook and Documentation?

Ask the assistant to check project services and provide available access points. An old URL may belong to a different project; local addresses are not permanent links. See [Resuming and handing off](reprendre-transmettre.md).

## Must I reinitialize tomorrow?

No, if the project is initialized. Ask the assistant to read current state and roadmap, then resume the next authorized step.

## How do I answer a question that is not clickable?

Reply with the desired label or request a numbered list. Native controls depend on the client and available tools. See [Working with your assistant](assistant.md).

## Where do I enter a key or password?

Do not paste it into chat. Ask for [private configuration](../agents/private-configuration.md). It can offer a local form or fallback file; that file displays values in the editor. Never distribute secrets with the kit.

## What if startup fails?

Report the attempted action and error without confidential values. Request diagnosis before deleting, reinstalling or altering data. The assistant explains missing prerequisites and access limits; [technical operations](../operations.md) details procedures.

## Can I publish my project?

Local consultation and checks do not constitute publication. Request preparation covering hosting, access, data, costs and checks; publication and external services need their own authorization. See [Checking and deciding](verifier-decider.md).
