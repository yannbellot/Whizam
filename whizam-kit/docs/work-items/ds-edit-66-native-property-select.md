# DS-EDIT-66 — Sélecteur Propriété natif

Application, base 95f4f3c, branche codex/ds-edit-66-native-property-select. Mandat : corriger le second clic/débordement signalé et aligner Propriété sur les listes natives de UI Lab. Procédures applicatives diagnose-incident/implement-feature/test-user-flow ; contrôles et revues séquentiels, même agent, non indépendants. Sol · Élevée maintenue pour le contexte d’édition et la conservation des états ; correction localisée sans nouveau contrat métier.

Observation de code : le contrôle porté d’Apparence utilise un bouton combobox, un portail dans document.body, un positionnement mesuré et une gestion propre du focus/clavier ; les autres listes sont des select natifs. Le symptôme du second clic est signalé par le designer ; sa séquence exacte n’a pas pu être observée, l’accès au navigateur courant étant indisponible. Ne pas inventer de cause événementielle précise.

Solution : select natif avec optgroup, groupes et libellés du contrat conservés, aide CSS accessible sur le champ et hors popup ; supprimer le portail et ses styles/tokens devenus inutiles, actualiser le manifeste. Tester sélections répétées, clavier, changement de valeur, retour à la propriété initiale sans perte de brouillon, dimensions/mobile, types/lint/DS. Ne pas toucher au Storybook conservé ni abandonner un brouillon humain. Nouvelle recette distincte si l’état de l’onglet courant ne peut pas être vérifié. Critères : même élément select que les autres champs, absence de panneau HTML superposé, groupes conservés, valeur et attribution inchangées hors actions explicites.

Portail, gestion manuelle des clics/focus/clavier et positionnement supprimés ; trois tokens/primitives de popup retirés, sélection rattachée à son consommateur restant. Manifeste v18. Modèle/protocole métier et attributions inchangés.
