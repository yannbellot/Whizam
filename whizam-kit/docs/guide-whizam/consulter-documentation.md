# Consulter la documentation

**La documentation conserve les informations utiles pour comprendre, faire évoluer et transmettre votre projet.** Elle rassemble les contenus, les choix de conception, les décisions techniques et le suivi du travail.

L’assistant l’enrichit au fil des étapes. Vous pouvez la consulter pour vérifier l’avancement, retrouver une décision ou préparer la suite.

## Ouvrir la documentation

Dans votre conversation avec l’assistant, demandez :

> Ouvre la documentation de mon projet.

L’assistant vérifie l’accès au portail et le lance si nécessaire. Il vous indique les éventuels prérequis manquants.

**La documentation s’ouvre dans votre navigateur.** Son adresse dépend de votre environnement local : utilisez le lien vérifié par l’assistant pour accéder au bon projet.

## Se repérer dans le portail

Le portail est organisé en trois rubriques, accessibles depuis la navigation.

### Guide d’utilisation

**Le guide explique comment travailler avec Whizam.** Vous y retrouvez les étapes de démarrage, l’utilisation des outils, le partage du projet et les possibilités d’adaptation du kit.

### Suivi de projet

**Le suivi de projet rassemble l’état courant, la feuille de route et les étapes du travail.**

Vous y retrouvez les réalisations, les décisions en attente, les vérifications et les prochaines actions.

Dans un kit neuf, les modèles de suivi attendent le démarrage de votre projet. Ils sont renseignés progressivement avec vos objectifs et les réalisations.

### Documentation technique

**La documentation technique décrit le fonctionnement du projet et les conditions nécessaires à son exploitation.**

Elle couvre notamment l’architecture, les données, l’installation, la sécurité et les outils de développement. Elle sert de référence à l’assistant et facilite la reprise par une équipe technique.

Vous pouvez demander à l’assistant de vous expliquer un document ou les conséquences d’un choix technique.

## Suivre l’avancement du projet

Dans **Suivi de projet**, trois repères vous permettent de comprendre où en est le travail :

- **L’état courant** indique ce qui a été réalisé, les décisions en attente et la prochaine action.
- **La feuille de route** présente les objectifs, les chantiers et leur avancement.
- **Les étapes du projet** regroupent les documents de préparation, de vérification et de décision associés au travail effectué.

**Un résultat techniquement vérifié peut encore attendre votre acceptation.** Le suivi distingue ces deux moments pour éviter de présenter comme terminé un travail qui reste à examiner.

## Retrouver une information

Utilisez la navigation pour parcourir les rubriques ou **la recherche du portail** pour retrouver un terme, un composant ou une décision.

Vous pouvez aussi interroger directement l’assistant :

> Où avons-nous documenté le fonctionnement de l’inscription ?

> Quelles décisions restent à prendre avant la prochaine version ?

> Résume les changements réalisés depuis notre dernière séance.

L’assistant consulte les documents du projet pour vous répondre et vous indique les sources utiles.

## Garder une documentation à jour

**Les modifications du projet doivent être accompagnées de la mise à jour des documents concernés.** Même si Whizam, met à jour automatiquement sa documentation, vous pouvez demander à l’assistant de vérifier leur cohérence :

> Vérifie que la documentation correspond à la version actuelle du projet et signale les informations manquantes ou dépassées.

Si vous repérez une erreur, indiquez la page et la correction souhaitée. L’assistant pourra modifier le fichier source correspondant.

La documentation fait partie du dossier de votre projet. **Elle accompagne sa transmission** et permet à une autre personne de comprendre le travail réalisé, ses limites et les prochaines étapes.
