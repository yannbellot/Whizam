# Préparer son kit

Travaillez sur une copie du kit pour conserver un modèle réutilisable. Choisissez un emplacement pour votre projet et gardez ensemble ses fichiers, y compris les fichiers cachés nécessaires et les liens internes. Ouvrez ce dossier comme racine dans votre assistant de développement.

## Avant de commencer

Préparez votre intention ou votre brief si vous en avez un. Vous pouvez aussi demander une démonstration. Aucun choix d’assistant n’est demandé : chaque outil suit son point d’entrée. Les adaptateurs ont leurs propres limites de compatibilité ; leur présence ne prouve pas un essai dans votre environnement.

L’assistant doit vérifier l’état du dossier et les prérequis avant toute installation. Certaines opérations sur votre poste peuvent nécessiter votre intervention ou une autorisation de l’outil. Il doit expliquer ce qui manque et son effet sur la suite.

> Exemple : « Je travaille avec Codex. Vérifie les prérequis de cette copie du kit et prépare une proposition pour démarrer mon projet. »

Le résultat attendu est un état clair : dossier visé, outils disponibles, éléments manquants et proposition de préparation. Un dossier déjà utilisé doit être préservé ; ne demandez pas une remise à zéro pour résoudre un problème de lancement.

Après validation de la proposition, l’assistant peut préparer l’environnement dans le périmètre convenu. La préparation technique n’invente pas les fonctionnalités du projet.

Passez ensuite à [Créer son premier projet](premier-projet.md). Les détails d’installation sont dans le [README](../../README.md), la [préparation de l’environnement](../../skills/initialize-project/references/environment-setup.md) et la [notice de distribution](../distribution/README.md).
