# Nommage des tokens

Selon la [politique courante](policy.md), utiliser `primitive.*`, `component.*` ou `local.*` ; identifiants techniques anglais, stables et explicites. Une identité inclut un propriétaire et un usage ; les composants distinguent variante, partie et état. Les métadonnées portent la catégorie et le propriétaire, avec contexte de composant si nécessaire.

Ne pas introduire de préfixe semantic/decision, d’exception d’instance ou de référence de token de composant vers un autre composant. Les identifiants historiques conservés et les correspondances sont dans la [table de migration](simple-token-migration.json). Les variables CSS sont des dérivés, pas la source du nommage.
