# 044 — Cadrage conditionnel et politiques par point d’entrée

20 novembre 2026 — logique mandatée ; réalisation à soumettre à acceptation.

Le [cadrage canonique](../agents/project-intake.md) remplace le choix d’assistant et le questionnaire linguistique préalable. Les points d’entrée appliquent leurs politiques propres sans lire l’ancienne préférence d’assistant. Les règles restent communes ; aucune sélection réelle de modèle ou détection par présence de fichiers n’est revendiquée.

Les réponses sont conservées dans le brief et le point de reprise. Le premier niveau utilise les choix natifs avec précisions facultatives ; le second est une réponse normale dans la conversation. Une démonstration propose Q1–Q6 puis reprend à Q7 ; la réalisation attend la validation de la synthèse complète. Les [langues du projet](../agents/languages.md) distinguent application et documentation et étendent les préférences existantes sans les perdre.

Cette décision remplace les règles de choix d’assistant des décisions 042/043 et l’ordre linguistique initial, sans modifier les permissions natives, les accords matériels requis, l’acceptation humaine ou les preuves historiques. Les anciens états privés ne sont ni effacés ni distribués. Aucun ancien chantier de test n’est réactivé.
